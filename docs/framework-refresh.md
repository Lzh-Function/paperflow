# 検証と図表表示

## 通常の検証

通常のノート更新は`check_changed.py`で1回検証する。ノートの読み込み、リンク索引、見出し・blockの解析結果を同じ実行内で共有する。

```powershell
python scripts/check_changed.py --path "10_Papers/20_Source_Notes/論文.md" --path "70_Review/Merge_Proposals/提案.md" --brief
```

複数パスは`--path`を追加するか、`--paths-file`で相対パスのJSON配列を渡す。変更したノートと既存の参照元を検査し、ID・名前の重複は既存ノートの文脈も参照する。

Properties、語彙、タグ、リンク、参照見出し・block、型付き関係、引用形式を確認する。書き込み時のロック、変更前ハッシュ、復旧用バックアップも維持する。

成功後に同じ4検証器や`wiki_lint.py`を重ねて実行しない。文章やリンクを変更した場合に、その変更を検証し直す。

## 全体監査

ライブラリ全体の整備や監査では、次を実行する。

```powershell
python scripts/wiki_lint.py --no-write
```

通常の取り込みごとに過去の全PDFを再ハッシュしない。学術的な意味の照合は、Wikiへ採用する主張と必要な原典位置を対象とする。機械検証を学術的正しさの証明として記録しない。

Windows実機でSource Note・提案6ファイルを検証した測定では、個別4プロセスの合計24.033秒に対し単一検証は5.248秒だった。要約生成を含む処理全体の時間やトークン削減率を示す値ではない。計測値は`.data/framework-refresh/benchmark.json`。

## 図表表示

要約担当AIが本文とPDF/全ページ画像を読み、重要な図表を選んで日本語の説明を返す。プログラムが選択した図表を元PDFから切り出す。

Source Noteは要点・図表・説明・研究課題・手法・結果の順に表示し、長い根拠候補と処理記録は折りたたむ。境界が不明な図表はページ全体を表示する。既存ノートを一括再生成しない。
