# PDF照合の規則

BibTeXを正本として、設定されたPaperpileルート内で実際に検出したPDF候補だけを照合する。この工程はファイル名・サイズ・mtimeを参照し、PDF本文を開かず、原本とBibTeXを変更しない。

## 明示参照とフォルダ

- `file`の明示参照を優先する。絶対パス、ルートからの相対パス、file URL、`:path:PDF`に対応する。文字列を正規化して完全に比較し、原本ルート外の参照の末尾だけで別ファイルを採用しない。
- 自動照合では `All Papers` を主フォルダとする。同名ファイルが `Starred Papers` にもある場合は `All Papers` を採用する。Starredにしかない場合は通常の照合対象にする。
- `All Papers` 内に同名の候補が複数あれば保留する。異なるパスのファイルを同一内容とみなしてマージしない。
- `Trashed Papers` は自動採用しない。明示参照先がTrashedだけの場合も要確認として止める。
- Starredを単独で明示参照した場合はその指定を尊重する。All/Starred両方が明示された場合はAllを優先する。
- supplement / supporting等の補足資料は自動本文照合から除外する。

## タイトルと命名メタデータ

通常はUnicode・大小文字・句読点を正規化したタイトルで照合する。既知の `掲載誌_第一著者_最終著者_年_タイトル.pdf` という命名形式から著者・年・掲載誌を取り出し、BibTeXと矛盾する候補は自動採用しない。短い命名形式では証拠のない著者/掲載誌を捏造しない。団体著者は `Example Team` 等の完全な名前で扱う。

長い名前の途中が `...` / `…` に省略されている場合は、次をすべて満たす唯一候補だけを採用する。

1. 省略記号が1箇所で、その前後がBibTeXタイトルの先頭・末尾とそれぞれ完全に一致する。
2. 正規化した可視部分が前後各12文字以上、合計50文字以上、元タイトルの50%以上であり、実際に中間部分が省略されている。
3. 命名メタデータの第一著者と出版年がBibTeXと一致する。
4. 複数の妥当な候補が残らない。

この条件に届かない省略名を、類似度の閾値を下げて自動採用することはない。

## 版の区別

同じ題名でも、著者・年・掲載誌を用いてarXiv版と掲載版を別々に照合する。BibTeXのarXiv掲載誌、arXiv DOI、arXiv IDも版の区別に利用する。残る候補が複数あれば保留し、単に新しい年や掲載版を一律優先しない。

ファイル名だけで解決できない同一年・同著者・同誌の版違いは、`file`等での確認が必要。PDF本文や内部メタデータからのDOI抽出・ハッシュによる内容同一性の検証はこの工程では実施しない。

## 低信頼の候補

通常タイトルの類似度による照合は従来の高い閾値と候補間の差を維持し、著者・年・版の矛盾がある候補と不十分な省略名は自動採用しない。

`match_json.reason` に採用/保留の根拠を保存する。代表例は `truncated_title_author_year`、`exact_title`、`bibliography_mismatch`、`ambiguous_candidates`。`scan`の要確認項目にも `match_reason` を含め、Markdownレポートには理由を日本語で出力する。
